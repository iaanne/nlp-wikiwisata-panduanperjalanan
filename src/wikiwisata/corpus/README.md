# Corpus

Pemilik: Elias, dibantu Jimly pada fase pengambilan data.

File yang direncanakan:
- `fetch_wikiwisata.py`: ambil artikel, simpan respons mentah, dukung resume.
- `fetch_revisions.py`: ambil dua revisi untuk slice konflik.
- `parse_listings.py`: parsing templat senarai.
- `chunkers.py`: chunk tetap, per bagian, dan per butir senarai.
- `build_source_register.py`: URL, tanggal, revision id, SHA-256, lisensi.

Aturan: build indeks harus bisa jalan offline dari source register.
