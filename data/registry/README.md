# Registry

Metadata kecil yang harus ikut git:
- `source_register.csv`: URL, tanggal, revision id, SHA-256, lisensi.
- `conflict_pairs.csv`: pasangan revisi untuk slice konflik.
- `corpus_stats.json`: jumlah dokumen dan butir yang benar-benar terpakai.

File di sini tidak boleh memuat data pribadi.
