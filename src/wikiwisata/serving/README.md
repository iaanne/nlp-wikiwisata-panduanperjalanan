# Serving

Pemilik: Jimly.

File yang direncanakan:
- `api.py`: endpoint pertanyaan dan tanggal perjalanan.
- `fallback.py`: mode jawaban terbatas saat retrieval gagal.
- `tracer.py`: trace dan log per request.
- `ui_app.py`: UI jawaban, sitasi, tanggal data, dan status abstain.

Kontrak output memakai `schemas/answer.schema.json`.
